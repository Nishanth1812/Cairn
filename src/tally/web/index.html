How these numbers are measured
Tokens processed
fresh input + cache read + cache write + output, over every model call. Mostly cache reads, because each call re-reads the whole conversation.
Newly paid
fresh input + cache write + output: the tokens that were not a cache hit.
Cache hit
cache read ÷ (fresh input + cache read + cache write).
Tokens/sec
output tokens ÷ wall time of the call, for calls with 30+ output tokens. Includes time to first token, so it understates raw generation speed.
API-equivalent cost
tokens × list price. What the same usage would cost on the API; a subscription does not bill this. A tilde (~) means part of it is estimated.
Turn
everything the agent did to answer one prompt of yours, subagent calls included.
Privacy
logs are read from this machine and served from localhost. Nothing is uploaded.
